# Harvestar AI — Qatar farm advisor

3,000 chat conversations for fine-tuning a small model (Unsloth / TRL SFT) into a farm advisor for
Qatar. There is one file, `harvestar-ai-qatar.jsonl`, with one conversation per line:

```json
{"messages": [
  {"role": "system", "content": "You are Harvestar AI, an agronomy and farm-economics advisor for Qatar. ..."},
  {"role": "user", "content": "Q1: What is the best use for this land?\n\n{\"task\":\"land_analysis\",\"as_of\":\"...\",\"inputs\":{...},\"context\":{...},\"derived\":{...},\"evidence\":[...]}"},
  {"role": "assistant", "content": "{\"task\":\"land_analysis\",\"summary\":\"...\",\"insights\":[...], ...}"}
]}
```

- **Q1** (1,500 rows), land suitability: what should this land be used for, which crops, in what type of
  farm? The answers weigh the water, the market, trade and politics, and Qatar's 2030 food-security goals.
- **Q2** (1,500 rows), inquiries about a farm that is already growing: irrigation today, risks this week,
  harvest and prices, and the next crop.

The user turn is `Q1: <question>` or `Q2: <question>`, a blank line, then the input as JSON. The input has
nine fixed inputs: latitude, longitude, ecosystem, growable_crops, air_temperature, relative_humidity,
wind, rain and soil_moisture. It also has the farmer's context, values derived by code, and dated evidence
(news, research and datasets) with ids. The assistant answers with one JSON object whose keys are always
`task, summary, insights, warnings, forecast, economic_advice, recommendations, crop_plan, sources, data_gaps`.
Each key is one section of the app's page, with a fixed shape:
- warnings carry a `when`;
- `forecast.days` holds seven dated chips (`date`, `label`, `level`);
- `crop_plan` holds the choice first, the crops to avoid, and a harvest window for Q2.

Every string is one line of plain text, so the website can split the answer into its sections with
`JSON.parse` alone.

Every number and date in an answer appears in its input, and every citation points at an evidence item.
**Qatar only:** every site is inside Qatar (7 municipalities), and no answer names another country.

Conversations are 6,702 Qwen3 tokens on average and at most 8,894, so use `max_seq_length` ≥ 8,960 (9,216 is a safe choice).

```python
from datasets import load_dataset
ds = load_dataset("json", data_files="harvestar-ai-qatar.jsonl", split="train")  # or load_dataset("<user>/<repo>", split="train")
```
